# `NLP-AT-COGSCI`
This book is intended for use at the *Natural Language Processing* course on the Cognitive Science MSc. for the autumn semester of 2025. 

# Setup
Note that `requirements.txt` in the root directory refers to the packages needed to make the `teachbooks` run, whereas there are seperate python requirements!

[py_requirements_E2025.txt](/materials/py_requirements_E2025_.txt) was used for all classes in E2025, and for the first 4 classes in E2026. 

For class 5, I was forced to update `transformers` and a bunch of other packages, hence: 
[py_requirements_E2026.txt](/materials/py_requirements_E2026.txt)
- Note that this won't work for the first few classes due to `textdescriptives` needing a lower version of `numpy`!
