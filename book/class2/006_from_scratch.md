## Exercise 6: "From the Ground Up": Building NNs
Today's "from scratch" exercise cheats a tiny bit, since it actually relies on [PyTorch](https://docs.pytorch.org/docs/2.14/index.html). Nevertheless, in contrast to scikit-learn, it Pytorch provides more lower-level building blocks for constructing classifiers (whereas with scikit-learn you would import [MCPClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.neural_network.MLPClassifier.html)). 

In the interest of time, I'll keep this exercise relatively short with the aim:
```{admonition} AIM
Familiarize yourself with PyTorch's building blocks for neural nets!
```
