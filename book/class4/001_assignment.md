## {darkblue}`Steps`
1. **Find an interesting text dataset**  
	(e.g., a place with text data such as kaggle.com or huggingface.co. Also fine if you have access to data elsewhere.)

2. **Describe the dataset concisely**
	1. What is it? Where is it from?
	2. Any possible ethical issues?

3. **Write research question(s)** 
	1. Define at least one RQ that may be interesting to answer with your dataset
	2. Describe how you plan to answer the RQ

4. **Begin addressing the RQ by applying ANY methods (in Python) learned so far**
	1. You can rely on the workbook for this
	2. You don’t need to fully answer the RQ ! Keep it simple!

5. **Describe your approach**
	1. Which methods did you use or do you plan to use?
			 	(e.g., main concepts, Python libraries …)
	2. Which assumptions/considerations did you make?
				(e.g., how did you choose to represent your text data?) 

6. **Create at least one visual aspect**    
	(e.g., plot/table from point 4, illustration of pipeline …)

7. **Save your code in a GitHub repository**
    1. Try to follow the good code practices learned in class 4 
    2. If relevant, save your results / plots to this repository as well

8. **Hand-in your report on Brightspace, incl. a link to the repository in the report**
