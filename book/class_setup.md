At the beginning of most NLP classes, you will need to go through the same workflow before proceeding to the coding exercises.

:class: red
Go through [Step 1](/book/class_setup/001_running_jobs.md) & [Step 2](/book/class_setup/002_jupyter.md), following each step in your own UCloud. 

For [Step 3](/book/class_setup/003_rerun.md), you can make do with just *reading* the guide.

## Can I Freestyle?
Although I encouraging freestyling normally, **I recommend sticking to this exact workflow (including folder names)** for two reasons: 

1. It makes it easier to use provided code snippets. 
2. Troubleshooting will also be wayyyy easier if we all have the same setup (i.e., it often becomes a collective problem-solving problem!)

> If you are already a UCloud pro (i.e., don't need detailed guides), I suggest you use the summaries at the top & skim through!
