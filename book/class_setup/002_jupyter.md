# Step 2. Set up Jupyter Notebook in Coder Python

The sections below give you a step-by-step on how you should create notebooks. A short summary of this is: 
1. Create an `nbs` folder in your `nlp` folder
2. Create a jupyter notebook (`.ipynb`) from scratch or use the provided template, placing it within `nbs`

## Starting Point
If you followed {ref}`Step 1 <mounting-folders>`, you should have the following folders in your Coder Python:

## Adding a New Notebook
I recommend creating a folder called **nbs** (short for "notebooks") in your **nlp** folder by right clicking the sidebar. 

Then **add a file** with the extension `.ipynb` e.g., `class1.ipynb`

```{figure} ../figures/class_setup/step2-nbs-folder.png
---
name: nbs-folder
---
```

:::{admonition} Drag & Drop
:class: tip
You can ALSO drag a notebook from your computer onto the sidebar and into the `nlp` folder (e.g., a template)
::: 

## Setting up the Notebook
During class exercises, some sections will involve reading code, while others will require you to write code yourself.

**I recommend creating an empty notebook or using a template “skeleton.”** You can then copy and paste code as needed, for example when experimenting with a snippet on your own or completing a `hands-on` exercise.
