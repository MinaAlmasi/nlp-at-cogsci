# Step 2. Set up Jupyter Notebook in Coder Python

The sections below give you a step-by-step on how you should create notebooks (to standardise across the class). A short summary of this is: 
1. Create an `nbs` folder in your `nlp` folder
2. Create or use the provided template to create a jupyter notebook `.ipynb` within `nbs`

## Adding a New Notebook
I recommend creating a folder called `nbs` (short for "notebooks") in your `nlp` folder by right clicking the sidebar. Add then a file with the extension `.ipynb` e.g., `class1.ipynb`

```{figure} ../figures/class_setup/step2-nbs-folder.png
---
name: nbs-folder
---
```

> You can ALSO drag a notebook from your computer onto the sidebar and in the `nlp` folder (e.g., a template)

## Setting up the Notebook
During class exercises, some sections will involve reading code, while others will require you to write code yourself.

I recommend creating an empty notebook or using a template “skeleton.” You can then copy and paste code as needed, for example when experimenting with a snippet on your own or completing a `hands-on` exercise.
