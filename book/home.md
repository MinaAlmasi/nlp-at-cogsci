### Structure
I have tried to structure in a chronological way for the most part - so you'll proceeding from technical setup in `Getting Started` to exercises and code intro in `Classes`. 

**Importantly**, there are a few elements you should keep an eye out for. *Red* boxes are supposed to make you stop and either consider a `QUESTION` or get you started with a `HANDS-ON` coding exercises.

```{admonition} HANDS-ON
:class: red

Do the following task ... 
```

For tips and help, look for the green`tip` boxes:
```{admonition} For loops? I need the basics!
:class: dropdown, tip
For loops are ..
```
