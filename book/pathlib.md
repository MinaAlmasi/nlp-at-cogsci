# Pathlib
So far, we have been using `pathlib` passively, where I have given you the paths. As we progress and start to work on code on our own, it might become a bit challenging!

You might especially run into some issues when working with scripts and notebooks. To guide the process, I have given you a short intro on how to navigate with `path.parents[n]`!
