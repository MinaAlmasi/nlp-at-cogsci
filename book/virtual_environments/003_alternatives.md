# Alternatives!
If you do not want to use `.venv`, a pretty awesome alternative is `uv`. You need to install it before using it which is described in `uv`'s [Installation](https://docs.astral.sh/uv/#installation) section. Otherwise the commands are *very* similar to the `venv` module (see [docs](https://docs.astral.sh/uv/pip/environments/)).

```{important}
I recommend only using `uv` outside of the NLP classes, and only if you are a power user who is familiar with virtual environments, managing code projects and writing commands in the terminal. 
```
